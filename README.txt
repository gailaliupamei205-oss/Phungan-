PHUNGAN CALCULATOR PROJECT

Files:
- main.py: complete app with welcome screen and calculator
- phungan_calculator_icon.png: your chosen photo cropped into a square icon
- buildozer.spec: basic settings for building an Android APK

To try it in Pydroid 3:
1. Extract this ZIP into a folder on your phone.
2. Open main.py in Pydroid 3.
3. Install Kivy in Pydroid's Pip section if it is not installed.
4. Press Run.

The Android app icon setting in buildozer.spec is already configured.
This project does not contain an APK yet; building the APK requires a computer or a compatible cloud build setup.
